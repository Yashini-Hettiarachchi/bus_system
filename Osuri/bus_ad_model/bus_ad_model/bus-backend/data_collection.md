# Data Collection Description

## Purpose
Collect real-world bus journey data by recording specific details at each city stop during bus routes.

## Responsibilities
- At each city stop, record the following information:
  - Journey start time
  - City name
  - Arrival time at city
  - Direction (forward or reverse)
  - Time of day (morning, midday, evening, night)
  - Bus speed (average speed between cities and time of day)
- Ensure all data is accurate and complete
